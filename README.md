# GoIoT Platform

**GoIoT Platform 是一个基于 Go 语言构建的开源物联网设备接入与管理平台，以 MQTT 为核心通信协议，为不同类型的物联网设备提供统一、安全、可扩展的接入与管理能力。**

## 项目背景

随着物联网设备数量不断增长，设备接入、身份认证、消息传输、设备状态维护、数据采集和远程控制等需求日益复杂。不同设备往往具有不同的身份标识、数据格式和业务行为，缺少统一的接入与管理机制会增加系统开发和维护成本。

GoIoT Platform 希望通过统一的设备接入模型、标准化的消息处理流程和模块化的系统架构，降低物联网应用的开发门槛，为智能家居、环境监测、工业数据采集和其他物联网应用提供基础平台能力。

## 项目目标

* **统一设备接入：** 基于 MQTT 实现设备连接、身份认证和消息通信。
* **统一设备管理：** 管理产品、设备、设备凭证、设备状态及生命周期。
* **统一数据处理：** 接收设备上报数据，完成数据校验、解析、存储与分发。
* **设备双向通信：** 支持设备属性上报、服务调用、远程命令下发及执行结果反馈。
* **灵活的业务扩展：** 通过规则引擎、消息路由和插件化协议适配能力扩展业务。
* **易于部署和维护：** 提供清晰的模块边界、配置管理、日志、监控和自动化部署能力。

## 核心设计原则

1. 设备接入与业务管理解耦。
2. 设备身份、产品模型和消息格式统一。
3. 优先保证消息处理的可靠性、安全性和可观测性。
4. 先构建可运行的单体版本，再根据实际负载拆分独立服务。
5. 优先复用成熟的 MQTT Broker，不重复实现已有的协议基础设施。

## 预期应用场景

* 智能家居设备管理
* 温湿度、空气质量等环境监测
* 工业设备数据采集
* 设备远程控制与状态监控
* 物联网数据转发及第三方系统集成
